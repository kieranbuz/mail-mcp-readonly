# mail-mcp-readonly

mail-mcp-readonly is a personal tool. It lets the owner's own AI assistant read the owner's own Gmail accounts, on the owner's own computer.

## What it does

- Reads mail, with read-only access (the Gmail `gmail.readonly` permission). It cannot send, delete, label or change anything in a mailbox.
- Runs only on the owner's computer. There is no hosted service, no website login and no public sign-up.
- Is used only with Google accounts that belong to the owner.

## Who it is for

Only the owner. It is not offered to the public, and other Google accounts cannot use it to reach anything.
